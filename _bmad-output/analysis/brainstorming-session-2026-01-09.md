### Core Concept

**핵심 워크플로우:**
```
문제 발굴 → 문제 정의 → 고객 개발 → 시장 개발
```

**핵심 기능:**
- 🎨 Node 기반 UI (시각적 워크플로우)

## Technique Selection

**Approach:** Progressive Technique Flow (점진적 기법 흐름)
**Journey Design:** 아이디어에서 행동까지 체계적 개발

## Phase 3: Idea Development (SCAMPER Method)

**Technique:** SCAMPER - 체계적인 제품 개선과 혁신을 위한 7가지 렌즈
**Energy:** 빌딩, 향상, 타당성 중심
**Duration:** 20-30분

### S️⃣ SUBSTITUTE (대체) - 결정 사항 확정

**사용자 결정:**
1. **AI 모델:** Claude 4.5 / GLM 4.7 (한국어 특화 모델 불필요)
2. **UI 스타일:** Node UI + 캔버스 (대시보드 아님) + 사이드바 채팅
3. **산출물:** 문서 중심 + 나노 바나나 수준의 인포그래픽/Figure

**핵심 혁신:** Claude 4.5와 GLM 4.7의 멀티모달 능력으로 텍스트와 시각 자료 동시 생성

### C️⃣ COMBINE (결합) - 시너지 발견

**주요 결합:**
1. **AI 공동 창업자 + 인포그래픽 생성** = 시각적 비즈니스 파트너
   - AI가 텍스트와 시각 요소를 동시에 생성
   - 문서만 나오는 게 아니라 전문가급 시각 자료까지

2. **Node UI + 구글 드라이브** = 문서들이 노드가 되어 스스로 연결
   - 문서들이 2D 공간에서 "살아있는 지도"가 됨
   - 자동 연결 감지 및 시각화

3. **채팅 사이드바 + 캔버스** = 대화하면서 시각적 워크플로우 구성
   - 대형 언어 모델(LLM)이 시각적 편집자가 됨

4. **린스타트업 워크플로우 + 인포그래픽** = 각 단계마다 자동 시각화
   - 문제 계층도, 페르소나 카드, 시장 지도, 9블록 캔버스 등

### A️⃣ ADAPT (적응) - 우선순위 확정

**사용자 결정:**

1️⃣ **MUST-HAVE (MVP)** - Figma/Notion/Miro 스타일
   - 실시간 협업 (댓글, @멘션)
   - 블록 기반 Node 시스템
   - 무한 캔버스

2️⃣ **SHOULD-HAVE (초기 릴리스)** - VS Code 스타일
   - 명령 팔레트 (Ctrl+Shift+P)
   - 확장 시스템 (커뮤니티 템플릿)

3️⃣ **COULD-HAVE (별도 모드)** - 게이미피케이션
   - 🎮 "퀘스트 모드" - 토글 가능!
   - 끌 수 있음 (기본 OFF)
