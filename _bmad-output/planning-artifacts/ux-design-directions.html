BM-Builder 디자인 방향성

상호작용 흐름 탐색: 채팅 ↔ 그래프 ↔ 문서

🎯 상호작용 흐름 디자인 방향성

BM-Builder의 핵심 경험은 "대화하면서 실시간으로 미리보기를 확인하고, 언제든 완료해서 문서를 받는다"입니다.

6가지 디자인 방향성은 사용자가 채팅, 그래프 시각화, 문서 미리보기 사이를 어떻게 이동하는지를 다르게 접근합니다.

💬 채팅

AI와 대화하며 요구사항 전달

🕸️ 그래프

지식 그래프 실시간 시각화

📄 문서

생성된 문서 실시간 미리보기

방향 1: 동시적 분할 (Simultaneous Split)

50:50 고정 분할 - 모두 함께 보기

기본 접근
💬 대화 + 🕸️ 그래프
"프로젝트 구조를 문서화해줘"
"네, 분석하고 있습니다..."
메시지 입력...
📄 문서 미리보기

🔄 상호작용 흐름

1. 대화 입력
왼쪽 상단 채팅
→
2. 그래프 생성
왼쪽 하단 시각화
→
3. 문서 업데이트
오른쪽 실시간 반영

✅ 장점

  • • 모든 정보를 동시에 확인 가능
  • • 실시간 동기화가 직관적
  • • 넓은 화면에서 최적의 경험
  • • 문맥 유지가 용이

⚠️ 단점

  • • 작은 화면에서는 공간 부족
  • • 각 영역이 좁아질 수 있음
  • • 주의가 분산될 가능성
  • • 모바일 친화적이지 않음
🎯 최적 사용 시나리오: 데스크톱 사용, 복잡한 문서 작성, 실시간 피드백이 중요한 경우

방향 2: 플로팅 패널 (Floating Panel)

주요 콘텐츠에 집중 + 필요시 플로팅

유연한 접근
🕸️ 그래프 캔버스
💬 대화
"이 노드를 설명해줘"
"이 노드는...
📄 미리보기

🔄 상호작용 흐름

1. 그래프 탐색
전체 화면으로 시각화
↔️
2. 필요시 채팅
플로팅 패널로 대화
↕️
3. 필요시 미리보기
플로팅 패널로 확인

✅ 장점

  • • 메인 콘텐츠에 최대 집중
  • • 필요한 도구만 호출
  • • 화면 공간 효율적
  • • 패널 위치/크기 조절 가능

⚠️ 단점

  • • 패널 관리 오버헤드
  • • 콘텐츠 가려질 수 있음
  • • 학습 곡선 존재
  • • 동시 확인이 어려움
🎯 최적 사용 시나리오: 그래프 탐색 위주, 간헐적 채팅/미리보기, 복잡한 시각화 작업

방향 3: 탭 전환 (Tabbed Interface)

단일 화면에서 탭으로 전환

심플 접근
"시스템 아키텍처를 설명해줘"
"네, 시스템 아키텍처는 다음과 같이 구성되어 있습니다..."
마이크로서비스
API 게이트웨이

🔄 상호작용 흐름

💬 대화
탭 클릭으로 전환
⇄
🕸️ 그래프
탭 클릭으로 전환
⇄
📄 문서
탭 클릭으로 전환

✅ 장점

  • • 매우 직관적인 인터페이스
  • • 화면 공간 최대 활용
  • • 모바일 친화적
  • • 낮은 학습 곡선

⚠️ 단점

  • • 동시 확인 불가능
  • • 문맥 전환 비용
  • • 빈번한 탭 전환 필요
  • • 실시간 동기화 감각 부족
🎯 최적 사용 시나리오: 모바일/태블릿, 단일 작업 집중, 간단한 문서 생성

방향 4: 자동 스위칭 (Auto-Switching)

AI가 컨텍스트에 따라 자동 전환

지능형 접근
● AI 자동 전환 중
📄 문서 미리보기 AI가 문서 완성을 보여줍니다

💡 문서가 거의 완성되었습니다. 계속 진행할까요, 아니면 그래프를 확인하시겠어요?

🔄 상호작용 흐름

1. 대화 시작
채팅 화면에서 시작
🤖
2. AI 판단
컨텍스트 분석 후 자동 전환
→
3. 최적 화면
그래프/문서로 자동 이동

✅ 장점

  • • 사용자 의도 파악
  • • 수동 전환 최소화
  • • 자연스러운 흐름
  • • AI 가이드 경험

⚠️ 단점

  • • AI 판단 오류 가능
  • • 사용자 제어권 감소
  • • 예측 불가능한 동작
  • • 오토 전환 끄기 필요
🎯 최적 사용 시나리오: AI 신규 사용자, 명확한 워크플로우, 가이드가 필요한 경우

🎯 최적 사용 시나리오: 복잡한 시스템 설계, 브레인스토밍, 공간적 사고가 중요한 작업

💡 추천 질문

  • 1. 주 사용자는 누구인가요? (초보자 vs 전문가)
  • 2. 주요 접근 기기는 무엇인가요? (데스크톱 vs 모바일)
  • 3. 동시 확인의 중요도는 얼마인가요? (높음 vs 낮음)
  • 4. 학습 곡선 허용 범위는?
  • 5. 가장 중요한 사용 시나리오는?

🎯 상황별 추천

  • ✓ 초보자 + 모바일: 방향 3 (탭 전환)
  • ✓ 데스크톱 + 실시간 피드백: 방향 1 (동시적 분할)
  • ✓ 전문가 + 복잡한 작업: 방향 5 (통합 캔버스)
  • ✓ 유연성 중요: 방향 2 (플로팅 패널)
  • ✓ AI 가이드 원함: 방향 4 (자동 스위칭)
