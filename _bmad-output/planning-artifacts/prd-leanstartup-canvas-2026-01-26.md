# Product Requirements Document: 린스타트업 캔버스

**Author:** Donggyu

**Status:** Draft - Step 10 Complete

## Executive Summary

### 비전

린스타트업 캔버스는 예비 창업자와 함께 아이디어를 발전시키는 AI 공동 창업자 플랫폼입니다. 무한 캔버스에서 노드를 연결하며 생각을 확장하고, AI가 맥락을 이해하며 개인화된 가이드를 제공합니다.

### 문제 정의

**사용자 피드백:**
> "가이드가 없어서 어떻게 쓰는지 모른다. 대시보드가 너무 일반적이라 노드 기능을 발견조차 어렵다."

**근본 원인:**
1. 진입 경로가 대시보드로 설정되어 캔버스 발견 불가
2. 첫 방문자 온보딩 없음
3. 린스타트업 7단계 시각화 부족
4. 미리 정의된 노드만으로 창의적 제약
5. 창업 결정의 고립감: 혼자 모든 것을 결정해야 하는 심리적 부담
6. 기존 자료 활용 부족: 이미 작성한 문서와의 통합 부재

### 해결책

린스타트업 캔버스 제공 기능:
1. 온보딩 투어: 첫 방문 시 단계별 가이드
2. 무한 캔버스: 자유로운 노드 배치 및 연결
3. 7단계 템플릿: 문제 발굴부터 IR 자료까지 표준 노드
4. AI 통합 대화: 각 노드별 AI 질문-답변
5. AI 공동 창업자 경험: 맥락 인식 AI가 창업 파트너처럼 개인화된 질문과 피드백 제공
6. 진행 상태 시각화: 완료 표시, 진행률 표시
7. 정부지원사업 내보내기: 산출물 자동 변환

## Success Criteria

### 사용자 성공 기준

**박준혁, 이서연(예비 창업가) 성공 지표:**

#### 2주 내 첫 사이클 완성
- 7개 노드 생성 및 연결 완료
- 각 노드에서 AI 대화로 내용 작성
- 완료된 노드 시각적 표시

#### 첫 방문 10분 내 첫 노드 완성
- **온보딩 강화**: 첫 방문자가 10분 내 첫 노드 작성 목표
- 온보딩 투어로 빠른 캔버스 이해
- 간소화된 AI 질문으로 신속한 내용 작성
- 즉각적인 성취감으로 참여 유도

#### 첫 1시간 내 첫 가설 완성
- 가이드에 따라 "문제 정의" 노드 생성
- AI 대화로 문제 기술 초안 작성
- **시간 측정 분리**: 노드 작성 20분 + AI 대화 10분 = 총 30분
- 사용자 피드백: "내 아이디어를 시각화함"

#### 1주일 내 IR 자료 초안 생성
- 완성된 7개 노드 기반 생성
- 원클릭으로 15페이지 IR 자료 생성
- 투자자 피칭용 시각 자료 포함

### 비즈니스 목표

#### 3개월 목표 (MVP 런칭 후)

**수익 모델 (MVP):**
- **프리 티어 (확장)**: 무료 (월 30회 AI 생성, 3개 캔버스, 워터마크 포함)
  - 첫 30일 무제한 AI 체험
  - 온보딩 완료 보너스: 추가 10회 AI 생성
- **베이직**: 월 ₩5,000 (월 100회 AI 생성, 5개 캔버스)
- **프리미엄**: 월 ₩10,000 (무제한 AI 생성, 무제한 캔버스, 우선 지원)
- **스타트업 플랜**: 월 ₩25,000 (팀 3인, 공유 캔버스, 협업 기능, 정부지원사업 우선 변환)
  - 예비 창업가/초기 스타트업 타겟
  - 3개월 무료 체험 제공
  - 멘토링 세션 1회/월 포함

**사용자 채택:**
- 50명 Weekly Active Users (현실적 목표로 조정)
- 일일 평균 15분 캔버스 체류 시간
- 사용자 60%가 "아이디어 시각화 도움" 피드백

**참여도:**
- 주 2회 이상 로그인 50% 이상
- 생성된 노드 평균 3개 이상
- 노드 완료율 70% 이상

**가치 창출:**
- 5명 이상 "bm-builder로 창업 시작" 피드백
- 무한 캔버스 몰입감 만족도 4.0/5.0

**경쟁사 차별화:**
- Notion/Miro: 문서 작성 도구, AI 통합 없음, 정부지원사업 자동화 없음
- ChatGPT: 맥락 없는 질문-답변, 시각화 없음, 린스타트업 프레임워크 부족
- bm-builder: 맥락 인식 AI + 시각적 캔버스 + 정부지원사업 자동화의 3박자 조합

## User Journeys

### Journey 1: 첫 방문 - 온보딩

**Actor:** 박준혁 (29세, 대기업 개발자, 예비 창업가)

**Current State:**
- 로그인 → 대시보드 이동
- 대시보드에 문서 통계, 우선순위 목록만 표시
- "캔버스 진입 경로를 찾지 못함" 혼란
- 이탈

**Target State:**
1. 로그인 → 린스타트업 캔버스 바로 진입
2. 온보딩 투어 자동 시작:
   - "환영합니다, 박준혁님! 첫 번째 아이디어를 정의해볼까요?"
   - 화살표로 "여기 클릭하여 첫 번째 노드 생성" 가이드
3. 클릭 → 캔버스 중앙에 "문제 발굴" 노드 생성
4. 노드 클릭 → AI: "어떤 문제를 해결하고 싶으신가요?"
5. 텍스트 편집 후 다음 노드 추가
6. 30분 후: "내 아이디어가 시각화됨"

### Journey 2: 아이디어 발전 - 노드 확장

**노드 연결:**
1. 드래그앤드롭으로 "문제 정의" 노드 배치
2. Shift+드래그로 "고객 개발" 노드 연결
3. 연결선 화살표로 관계 표시
4. 캔버스 전체 맥락 확인

**AI 협업:**
5. "고객 개발" 노드 클릭
6. AI 사이드바: "대상 고객은 누구인가요?"
7. 사용자: "30대 직장인"
8. AI: "타겟 페르소나 생성" → 자동 생성
9. 사용자: 페르소나 수정, 승인

**시각적 피드백:**
10. 노드 완료 시 색상 변경 → 초록색 ✓
11. 진행률 바: "완료 2/7 노드"
12. 사용자 피드백: "진행 상태 시각화됨"

### Journey 3: 정부지원사업 자동 생성

**IR 자료 내보내기:**
1. 7개 노드 모두 완료 (초록색)
2. "내보내기" 버튼 클릭
3. AI: "정부지원사업 R&D 양식 생성 시작"
4. 진행률 표시 (10초)
5. 완료: "15페이지 IR 자료와 30페이지 지원서 생성"
6. 다운로드 버튼 → PDF, DOCX 다운로드

**Alternative Flow: 부분 내보내기 (3-6개 노드 완료 시)**
1. 3개 노드 완료 (초록색)
2. "부분 내보내기" 버튼 표시 ("7개 완료 필요" 안내와 함께)
3. 클릭 → AI: "지금까지 작성한 내용을 기반으로 초안을 생성할까요? (미완성 섹션 표시됨)"
4. 진행률 표시 (5초)
5. 완료: "초안 완성 (미완성 섹션: [리스트])"
6. 사용자: 미리보기 확인 후 다운로드

### Journey 4: 에러 복구

**Scenario 1: AI API 실패**
1. 사용자가 노드에서 AI 질문
2. "AI 서비스 연결 실패" 알림
3. 재시도 버튼 표시 (3회 자동 재시도)
4. 3회 실패 시 "계속 문제가 발생하면 지원팀에 문의하세요" 메시지

**Scenario 2: 오프라인 모드**
1. 사용자가 노드 작성 중 네트워크 단절
2. "오프라인 모드로 작동 중" 알림 표시
3. LocalStorage에만 저장됨 안내
4. 온라인 복구 시 "동기화 완료" 알림

## Product Scope

### MVP (3개월)

**현실적인 일정 (솔로 개발자 기준):**

**Phase 1: 기본 캔버스 (Week 1-2)**
- 상호작용 가능한 무한 캔버스 구현 - 노드 생성/이동/연결 기능 제공
- 7단계 노드 타입 정의 및 노드 컴포넌트
- 드래그앤드롭, 엣지 연결 기본 구현
- **목표**: 빈 캔버스에 노드 생성/이동/연결 가능

**Phase 2: AI 기본 통합 (Week 3-4)**
- 캔버스 우측 사이드바 구현
- AI 기본 통합 - AI 대화 시스템 연동, 각 노드별 질문-답변 기능
- 각 노드별 단순 AI 질문-답변 (정적 프롬프트)
- AI 응답을 노드 내용에 자동 저장
- **목표**: 노드 클릭 시 AI와 질문-답변 가능

**Phase 3: 온보딩 & 시각적 피드백 (Week 5-6)**
- 오버레이 튜토리얼 구현 (4단계)
- 노드 상태 시각화 (색상, 애니메이션, 이펙트)
- 진행률 바 및 헤더 상태 표시
- **목표**: 첫 방문자가 30분 내 첫 노드 완성

**Phase 4: 부분 내보내기 기능 (Week 7-8)**
- 3개 이상 노드 완료 시 내보내기 기능
- Markdown 내보내기 (MVP에서는 PDF/DOCX 변환 제외)
- AI 변환 없이 텍스트 기반 초안 생성
- **목표**: 완성된 노드 기반 마크다운운 내보내기

**Phase 5: 테스트 & 버그 수정 (Week 9-10)**
- 사용자 테스트 (예비 창업가 3명)
- 성능 최적화
- 주요 버그 수정
- **목표**: 50명 WAU 달성 가능하도록 안정화

**Phase 6: 베타 릴리스 (Week 11-12)**
- 결제 처리 시스템 연동 - 구독 관리 및 결제 기능
- 구독 관리 기능
- 배포 및 런칭 준비
- **목표**: 실제 서비스 런칭

**Core Capabilities:**

1. **진입 경로**
   - 루트 경로(`/`) → 린스타트업 캔버스 바로 진입
   - 대시보드는 `/dashboard`로 이동 (사이드바 접근)

2. **무한 캔버스**
   - 드래그앤드롭으로 캔버스 패닝
   - 마우스 휠로 줌 인/아웃
   - 미니맵으로 전체 맥락 확인

3. **린스타트업 7단계 노드**
   - 문제 발굴 (Problem Discovery)
   - 문제 정의 (Problem Definition)
   - 고객 개발 (Customer Development)
   - 시장 개발 (Market Development)
   - 솔루션 (Solution)
   - 비즈니스 모델 캔버스 (Business Model Canvas)
   - IR 자료 (Pitch Deck)

4. **노드 생성 및 연결**
   - 빈 캔버스 더블클릭 → 노드 타입 선택 모달
   - Shift+드래그로 노드 간 연결
   - 연결선 화살표로 방향 표시
   - **캔버스 자유도**: 7단계 템플릿 제공하되 자유로운 순서/배치/연결 가능
   - **가이드 vs 자유**: 첫 방문 시 템플릿 가이드, 이후 자유로운 창의적 사용 가능

5. **노드 상태 시각화**
   - 미시작: 회색 + 점선 테두리
   - 진행 중: 노란색 + 점선 테두리
   - 완료: 초록색 + 체크 마크
   - **시각적 피드백 강화**: 색상 변경 시 부드러운 전환 애니메이션 (300ms), 완료 시 축하 이펙트, 진행률 바 그라데이션 표시

6. **AI 통합 대화**
   - 각 노드별 AI 질문-답변으로 내용 작성
   - **AI 맥락 인식**: 이전 노드 내용 기반 연속적 질문, 사용자 입력 자동 저장, 전체 캔버스 맥락 공유
   - **린스타트업 방법론 기반 질문 (단순화)**:
     - 문제 발굴: "어떤 문제를 겪고 계신가요?"
     - 문제 정의: "구체적으로 어떤 상황에서 문제가 발생하나요?"
     - 고객 개발: "대상 고객은 누구인가요?"
     - (기술적 용어 제거하고, AI가 백그라운드에서 적절한 프레임워크 적용)
   - 문제 발굴: 문제 리스트, 우선순위
   - 문제 정의: 문제 상황, 타겟 사용자, 가설
   - 고객 개발: 페르소나, 인터뷰 스크립트
   - 시장 개발: TAM/SAM/SOM, 경쟁사 분석
   - 솔루션: 솔루션 개요, MVP 기능, 가치 제안
   - 비즈니스 모델: 9블록 캔버스, 수익/비용 계산
   - IR 자료: 슬라이드 구성, 차트/그래프 생성

7. **온보딩 투어**
   - 첫 방문 시 오버레이 튜토리얼 (건너뛰기 가능)
   - 4단계 가이드: 노드 생성 → 내용 채우기 → 연결하기 → 첫 성취
   - "다시 튜토리얼 보기"로 재활성화
   - **모바일 지원**: 터치 기반 노드 생성/연결, 모바일 최적화된 UI

8. **정부지원사업 내보내기**
   - **부분 내보내기**: 3개 이상 노드 완료 시 초안 내보내기 가능 (7개 완료 전)
   - 7개 노드 완료 시 전체 IR 자료 버튼 활성화
   - **AI 변환 예시**:

## Functional Requirements

### FR-001: 캔버스 진입

사용자가 루트 경로(`/`)로 접근 시 린스타트업 캔버스가 1초 이내에 로딩되어야 한다.

### FR-002: 노드 생성

사용자가 빈 캔버스 더블클릭 시 7단계 노드 타입 선택 모달이 표시되어야 하며, 타입 선택 후 500ms 이내에 새 노드가 생성되어야 한다.

### FR-003: 노드 이동

사용자가 노드를 드래그하여 캔버스 상에서 자유롭게 이동할 수 있어야 하며, 드래그 응답 지연시간이 100ms 이내여야 하고 드래그 종료 시 위치가 저장되어야 한다.

### FR-004: 노드 연결

사용자가 Shift+드래그로 한 노드에서 다른 노드로 연결선을 생성할 수 있어야 하며, 연결선이 100ms 이내에 렌더링되어야 하고 연결선에 화살표로 방향을 표시할 수 있어야 한다.

### FR-005: 노드 상세 보기

사용자가 노드 클릭 시 우측 사이드바가 200ms 이내에 로딩되어야 하며 해당 노드의 상세 내용을 확인하고, AI와 대화하여 내용을 수정할 수 있어야 한다. AI 제안 승인율은 70% 이상 목표이며, 사용자 수정 반영은 1초 이내에 처리되어야 한다.

### FR-006: 진행 상태 시각화

시스템이 각 노드의 완료 상태를 색상(회색/노란색/초록색)으로 시각화하고, 헤더에 "완료 X/7"과 진행률 바를 표시해야 한다.

### FR-007: 온보딩 튜토리얼

첫 방문자가 4단계 가이드를 통해 첫 번째 노드를 생성하고 완성할 수 있어야 하며, 온보딩 완료율은 90% 이상, 평균 완료 시간은 5분 이내여야 하고 건너뛰기와 재활성화가 가능해야 한다.

### FR-008: 정부지원사업 내보내기

사용자가 3개 이상 노드 완료 시 부분 초안 내보내기가 가능해야 하며, 7개 노드 완료 후 AI 기반 문서 변환을 시작해야 한다. AI 변환 성공률은 85% 이상이어야 하고 생성 시간은 10초 이내여야 하며, 생성된 문서를 PDF, DOCX로 다운로드할 수 있어야 한다.

### FR-009: 부분 진행 상태 내보내기

사용자가 3개 이상 노드 완료 시 부분 내보내기 버튼이 표시되어야 하며, 클릭 시 5초 이내에 완성된 노드 내용을 기반으로 초안을 생성해야 한다. 시스템은 미완성 노드를 "미완성: [노드명]" 형식으로 명시하고 완성 권장사항을 3개 이하로 표시해야 한다.

### FR-010: AI API 에러 처리

외부 AI 서비스 호출 실패 시 사용자에게 명확한 에러 메시지를 표시하고, 재시도 버튼을 제공해야 한다. 3회 연속 실패 시 지원 티켓팅 안내를 표시해야 한다.

### FR-011: 네트워크 오류 안내

네트워크 연결 불량 시 "오프라인 모드로 작동 중" 알림을 표시하고, LocalStorage에만 저장한다. 온라인 복구 시 자동으로 서버와 동기화한다.

## Non-Functional Requirements

### 성능

- 페이지 로드: 캔버스 페이지를 2초 이내에 로드 (Chrome DevTools, 3G 네트워크 기준)
- 노드 생성: 새 노드 생성을 500ms 이내에 완료 (Performance API 측정)
- AI 응답 속도:
  - 짧은 질문(100자 이내): 2초 이내 응답 시작, 5초 이내 완료
  - 긴 질문(100자 이상): 3초 이내 응답 시작, 10초 이내 완료
  - 응답 생성 중 "AI가 내용을 생성하고 있습니다..." 진행률 표시
  - 실제 사용자 경험 기반: 7개 노드 완성 평균 시간 30분 목표

### 확장성

- 100 WAU: 단일 데이터베이스 인스턴스 지원 (수직 확장)
  - 응답 시간: P95 < 500ms 유지
  - 리소스 사용량: CPU < 70%, 메모리 < 80%
- 1,000 WAU: 데이터베이스 인덱싱 최적화, 캐싱 전략 적용
  - 응답 시간: P95 < 1초 유지
  - 캐시 적중률: 80% 이상
- 10,000 WAU: CDN 배포, 읽기 전용 인스턴스 분리 (롱아웃 아키텍처 고려)
  - 응답 시간: P95 < 2초 유지
  - 가용성: 99.9% SLA

### AI 비용 최적화

- 프롬프트 템플릿 로딩 시간: 100ms 이내
- Claude API Anthropic 헤더 사용 (최대 200K 토큰 윈도우)
- 응답 캐싱: 단기 캐싱 (1시간) + 장기 저장 (벡터 DB)
- 프롬프트 관리: 노드별 프롬프트 템플릿을 DB에 저장, 동적으로 로드
- 비용 모니터링: 월간 AI API 사용량 추적 및 예산 알림 (월 $100 초과 시 알림, $200 도달 시 사용 제한)

### 접근성

- 키보드 단축키 지원 (Ctrl+Z: 실행 취소, Del: 삭제)
- 태블릿, 모바일 반응형 지원 (320px-1920px 브레이크포인트)
- 색맹/고대비 모드 지원 (WCAG AA 대비율 4.5:1 준수)
- **모바일 UX**: 터치 drag & drop (150ms 내 응답), 핀치 줌, 모바일 최적화된 레이아웃
- **WCAG 2.1 AA 준수**: 대비율 4.5:1, 키보드 내비게이션, 초점 표시

### 호환성

- Chrome 90+, Safari 14+, Edge 90+, Firefox 88+ 지원
- iOS Safari, Chrome Mobile 지원
- 권장 화면 크기: 1280px 이상
- 권장 해상도: 720px 이상
- **테스트 전략**: 주요 브라우저 최신 2버전에서 크로스 브라우징 테스트 수행
- **Progressive Enhancement**: 기능이 제한된 구형 브라우저에서도 핵심 기능 사용 가능하도록 degrade gracefully

### 데이터

- **상태 관리**: 클라이언트 상태 관리 + 서버 상태 동기화 기능
- **데이터 저장**: 노드 위치, 연결선, 내용을 10초마다 자동 저장
- **충돌 처리**: 즉시 UI 반영 + 충돌 시 "변경 사항이 있습니다" 알림 (사용자가 최신 버전 선택)

- **오프라인 지원**: LocalStorage 백업 + 서버 동기화 (온라인 시 자동 저장, 오프인 시 LocalStorage만 사용)
  - 온라인 복구 시 5초 이내 자동 동기화 (최근 변경사항 우선)
