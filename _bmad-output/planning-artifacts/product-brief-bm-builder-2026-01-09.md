# Product Brief: bm-builder

## Executive Summary

bm-builder는 창업가가 혼자서 모든 것을 결정하고 실행해야 하는 고립감과 리스크를 해결하기 위해 탄생했습니다. 우리는 단순한 문서 생성 도구가 아니라, 창업가의 여정을 함께하는 "AI 공동 창업자"를 만듭니다. 기존 문서와 지식을 임베딩하여 개인화된 결과물을 생성하고, 직관적인 Node 기반 UI로 복잡한 린스타트업 프로세스를 시각화하며, 정부지원사업과 IR 자료 작성의 번거로움을 제거합니다. 우리는 창업가가 "혼자가 아니다"라는 느낌을 갖게 하여, 더 나은 의사결정을 하고 성공할 확률을 높이는 것을 목표로 합니다.

### User Journey

#### 페르소나 A: 박준혁 (예비 창업가, 대기업 개발자)

**현재 상태 (As-Is): "야근 후 퇴근길에 고민만 하다가 잠"**

1. **발견:** 수요일 야근 후 밤 10시 30분, 지하철에서 남이 사업계획 작성하는 것 보며 "나도 저렇게 뭔가 시작해야 하는데..." 후감
2. **첫 시도 실패:** 금요일 밤 11시, 노트북 열고 "제품: ___" 적다가 멈침. 30분 동안 커서만 깜빡거리다가 유튜브 보러 감
3. **혼자서의 고군분투:** ChatGPT에 질문하지만 매번 새로운 프롬프트 작성해야 하고, AI가 내 맥락을 모름. 3시간 질문하고 답받기 반복하다 밤 2시에 포기
4. **포기:** 1개월 후 "아직 준비가 덜 됐어"라며 합리화하고 6개월 뒤로 미루기

**bm-builder 사용 후 (To-Be): "드디어 시작했다"**

1. **발견 & 온보딩:** 화요일 점심시간, "개발자 창업 커뮤니티"에서 bm-builder 발견. "프리티어: 무제한"에 바로 가입. 수요일 저녁 첫 로그인
2. **첫 경험:** "준혁님, 반갑습니다! 함께 창업 여정을 시작해볼까요?" AI가 구글 드라이브 문서 분석하고 내 경험 바탕으로 제안. "오, 이건 정말 나를 아네"
3. **첫 번째 성공:** 저녁 8시 30분부터 9시 20분 (50분) 만에 첫 번째 가설 완성. "50분 만에 내가 1주일 동안 고민한 것보다 더 많은 진전을 했어"
4. **일상적 사용:** 매일 아침 7시 30분 bm-builder로 오늘의 우선순위 확인. 저녁 8시-9시 30분 작업. AI와 함께 "이 방향 맞을까?" 논의하며 고립감 감소
5. **성공의 순간:** 2주 후 일요일 오후 3시, 첫 번째 린스타트업 사이클 완료. 10초 만에 15페이지 IR 자료 생성. "드디어 시작했어", "이제 실제로 창업할 수 있겠다"
6. **장기적 루틴:** 3개월 후 퇴사하고 본격적으로 창업. 정부지원사업 2개 수주. 매일 아침 bm-builder로 오늘의 우선순위 확인

#### 페르소나 B: 이서연 (예비 창업가, 프리랜서 디자이너)

**현재 상태 (As-Is): "비즈니스 용어는 낯설고, 디자인만 하고 싶어"**

1. **발견:** 클라이언트가 "본인 브랜드 없어?"라고 물음. "내 브랜드 갖고 싶은데..."라며 위축
2. **첫 시도 실패:** 엑셀 열고 "비즈니스 모델" 검색하니 밸류 프로포지션, 고객 세그먼트 같은 용어 나옴. "이게 한국말이야?"라며 40분 만에 좌절
3. **포기:** 2주 후 클라이언트 일에 쫓겨서 창업 계획 잊음. "나는 비즈니스엔 소질이 없어"

**bm-builder 사용 후 (To-Be): "비즈니스는 AI가, 나는 디자인에 집중"**

1. **발견 & 온보딩:** Dribbble Korea에서 bm-builder 리뷰 발견. 토요일 오전 11시 첫 로그인
2. **첫 경험:** "서연님, 디자이너시죠? 시각 자료는 제가 생성해드릴게요" Node 기반 UI가 직관적이라 디자이너도 이해
3. **성공의 순간:** 1주일 만에 IR 자료 완성. 전문적인 차트, 그래프 자동 생성. "비즈니스 문서 작성 안 했는데 완성됐어?"
4. **장기적 루틴:** 3개월 후 프리랜서 그만두고 브랜드 런칭. 매일 아침 10시-11시 bm-builder, 낮에는 제품 디자인에만 집중

#### 페르소나 C: 김태현 (Solopreneur, 1인 SaaS)

**현재 상태 (As-Is): "매일 밤 무엇부터 해야 할지 고민"**

1. **발견:** 월요일 밤 11시 30분, "기능 추가? 마케팅? 유료 광고? SEO?" 결정 패러리즘. 매일 밤 잠들기 전 고민 반복
2. **혼자서의 고군분투:** Notion으로 할 일 정리하지만 "오늘 뭘 해야 하지?" 매일 고민. ChatGPT는 "맥락 없는 일반적인 조언"
3. **시간 낭비:** IR 자료 만드는 데 2주, 정부지원사업 양식 맞추느라 2주 날림. "혼자서 모든 결정해야 해서 무거워"

**bm-builder 사용 후 (To-Be): "AI가 동료처럼, 의사결정 리스크 감소"**

1. **발견 & 온보딩:** Slack 커뮤니티에서 bm-builder 리뷰. 화요일 아침 9시 첫 로그인
2. **첫 경험:** AI가 Todo 앱 경쟁사 분석하고 우선순위 제안. "태현님, 오늘의 우선순위는 '마케팅 채널 테스트'예요"
3. **일상적 사용:** 아침 8시 30분 bm-builder로 10분 만에 오늘의 계획 확정 (기존 30분 고민). 저녁 7시 진행 상황 공유하며 AI와 "이 방향 맞아?" 논의
4. **성공의 순간:** 2주 후 IR 자료 2일 만에 완성 (기존 2주). 앤젤 투자자 3명 만남, 그중 1명 시드 투자 제안 (1억 원)
5. **장기적 루틴:** 3개월 후 월 150만 원 수익 (목표 달성). AI와 함께 결정하는 것이 일상

#### 페르소나 D: 최민지 (초기 스타트업 창업자, 2년 차)

**현재 상태 (As-Is): "IR 자료 만드는 데 2주, 정부지원사업 탈락"**

1. **발견:** 화요일 오전 10시, 이사회에서 "시리즈 A 준비 어떻게 되고 있어?" 압박
2. **혼자서의 고군분투:** PPT로 15페이지 IR 데크 만들기 (2주 소요). 매일 밤 9시-11시 작업. 완성 후 보니 "이거 우리 회사 자료랑 안 이어지는데?"
3. **정부지원사업 실패:** 지난해 3개 지원, 모두 탈락. 피드백: "평가 내용이 구체적이지 않다". 양식 맞추느로 각각 2주씩 날림
4. **감정:** "내가 비즈니스 문서 작성을 못 하나?", "시간만 낭비했어"

**bm-builder 사용 후 (To-Be): "기존 자료 활용, 2일 만에 IR 자료 완성"**

1. **발견 & 온보딩:** 창업자 네트워킹에서 bm-builder 추천. 목요일 아침 9시 첫 로그인
2. **첫 경험:** AI가 회사 자료 완벽하게 이해하고 시리즈 A 투자자에게 강조할 포인트 제안. "오, 우리 회사 완벽하게 이해했네?"
3. **IR 자료 작성:** 목요일 bm-builder로 IR 자료 생성 (2시간). AI가 시장 규모, 단위 경제 차트 자동 생성. 금요일 CTO와 검토: "와, 이거 우리 회사 자료 잘 반영됐네"
4. **정부지원사업:** AI가 "심사위원은 기술성, 사업성, 창업팀 역량을 봐요"라며 최적화. 3시간 만에 지원서 완성 (기존 2주). 이번엔 탈락 안 함 (통과)
5. **성공의 순간:** 1달 후 IR 자료로 앤젤 투자자 5명 만남. 그중 2명 시드 투자 제안 (각 3억 원). 정부지원사업 2개 수주 (각 5000만 원)

#### 페르소나 E: 정진우 (액셀러레이터 매니저, 2차 사용자)

**현재 상태 (As-Is): "팀별로 맞춤형 피드백 주는 데 시간 너무 많이 소요"**

1. **상황:** 연간 30팀 액셀러레이팅, 포트폴리오 20팀 관리. 각 팀별로 1:1 미팅으로 피드백 (1팀당 2시간)
2. **한계:** 시간 부족으로 모든 팀에 충분한 피드백 불가

**bm-builder 사용 후 (To-Be): "팀들이 자가 진단 가능, 내 시간 효율화"**

1. **발견:** 포트폴리오 팀 중 bm-builder 사용하는 팀의 진행 속도가 빨라서 궁금
2. **성공의 순간:** bm-builder 사용 팀들은 IR 자료 품질이 높음. AI 심사위원 기준으로 자가 진단 가능. 내 시간을 더 효율적으로 사용 (전체 팀 피드백 아닌, 정말 필요한 팀만 집중)
3. **장기적 루틴:** 액셀러레이팅 프로그램 시작 시 bm-builder 소개. 각 팀의 Node 그래프 확인하여 진행 상황 파악

## Core Vision

### Problem Statement

**"창업가는 너무 많은 결정을 혼자 내려야 하고, 그 리스크는 모두 본인이 져야 한다"**

창업가들이 겪는 핵심 문제:

1. **의사결정의 고립:** 동료 없이 모든 결정을 혼자 내려야 하는 압박감
2. **문서 작성의 부담:** 린스타트업 7단계부터 IR/정부지원사업 자료까지 수백 시간 소요
3. **지식의 단절:** 기존 문서, 회사 자료를 새로운 문서에 통합하기 어려움
4. **형식의 까다로움:** 정부지원사업 특화 양식, IR 투자자용 포맷을 맞추는 데 큰 노력
5. **품질의 불확실성:** 비전문가가 작성하거나 일반 AI가 생성한 문서는 전문성 부족

누구나 가장 고통스럽게 느끼나요?
- **초기 스타트업 창업자 (1-3년차):** 자금, 인력, 시간이 부족해서 모든 것을 직접
- **예비 창업가:** 아이디어는 있지만 어떻게 시작할지 몰라서 지체
- **혼자 창업하는 사람 (Solopreneur):** 팀이 없어서 모든 결정의 책임이 본인

### Problem Impact

이 문제가 해결되지 않으면:

- **창업 실패율 증가:** 잘못된 의사결정으로 시행착오 반복
- **자금 조달 실패:** 자료가 부실해서 투자를 받지 못함
- **시간 낭비:** 문서 작성에 너무 많은 시간을 써서 본업(제품 개발)을 소홀히
- **정부지원사업 기회 상실:** 복잡한 양식 때문에 지원을 포기하거나 탈락
- **번아웃:** 고립감과 스트레스로 창업을 포기

### Why Existing Solutions Fall Short

**기존 AI 도구 (ChatGPT, Claude, Notion AI):**
- ❌ 수동적 도구: 사용자가 모든 것을 주도해야 함
- ❌ 컨텍스트 부족: 대화 맥락을 기억하지 못함
- ❌ 시각 자료 없음: 텍스트만 생성, 인포그래픽 부족
- ❌ 문서 임베딩 불가: 기존 문서를 활용할 수 없음
- ❌ 워크플로우 부재: 단계별 가이드 없음

**문서 작성 도구 (MS Office, Google Workspace):**
- ❌ AI 기능 없음: 모든 것을 수동으로 작성
- ❌ 템플릿만: 정적 템플릿만 제공, 맞춤화 어려움
- ❌ 협업만: 문서 작성 가이드는 없음

**프로젝트 관리 도구 (Notion, Jira, Asana):**
- ❌ Node UI 없음: 목록/보드 기반, 시각적 워크플로우 부족
- ❌ AI 내장 부족: 제한적인 AI 기능
- ❌ 정부지원사업 특화 없음

### Proposed Solution

**bm-builder = AI 공동 창업자 + Node 기반 시각화 + 문서 임베딩 + 정부지원사업 특화**

**1. AI 공동 창업자 (능동적 파트너)**
- 단순한 질문/답변이 아니라, 능동적으로 제안하고 분석
- 의사결정 리스크를 줄이기 위해 데이터 기반 추천
- "이 방향이 맞을까?"라고 함께 고민하는 동료
- 가설 검증, 고객 개발, 시장 분석을 자동화

**2. 기존 문서 임베딩**
- 구글 드라이브 연동으로 hwp, docx, pdf 자동 스캔
- 기존 비즈니스 문서, 회사 자료를 컨텍스트로 활용
- RAG (Retrieval-Augmented Generation)로 기존 지식을 결과물에 녹여냄
- "우리 회사의 기존 문서를 그대로 활용해줘"

**3. Node 기반 시각적 워크플로우**
- 복잡한 린스타트업 프로세스를 직관적인 노드와 연결선으로 표현
- 드래그앤드롭으로 자유롭게 구성
- 무한 캔버스로 전체 과정을 한눈에 파악
- 단순함: 전문가를 위한 직관적 인터페이스

**4. 인포그래픽 자동 생성**
- Claude 4.5/GLM 4.7의 멀티모달 능력 활용
- 나노 바나나 수준의 전문가급 차트/그래프/Figure
- 논문 수준의 시각 자료를 자동으로 생성
- 문서에 자동 통합

**5. 정부지원사업 특화**
- 정부지원사업 양식에 맞춘 자동 생성
- AI 심사위원의 기준을 이해하여 최적화된 자료
- IR 자료, 사업계획서를 클릭 몇 번으로 완성

### Key Differentiators

**1. AI가 "동료" (Co-founder)가 되는 경험**
- 단순 도구가 아니라, 함께 고민하고 제안하는 파트너
- 능동적인 의사결정 지원: "이렇게 하는 게 어떨까?"
- 컨텍스트 인식: 현재 작업 중인 노드를 이해하고 맥락적 대화

**2. 문서 임베딩의 깊이**
- 단순히 참고가 아니라, 기존 문서의 내용을 "녹여내기"
- RAG로 사용자/회사의 고유한 지식을 결과물에 반영
- "우리 회사만의 맞춤형 자료"가 자동으로 생성됨

**3. Node UI + 정부지원사업 특화의 조합**
- 경쟁사는 Node UI가 있거나 정부지원사업 특화가 있음
- 우리는 둘 다: 시각적 워크플로우 + 정부지원사업 양식 완벽 지원
- 직관적 UI로 복잡한 문서 작성을 단순화

**4. 멀티모달 AI (텍스트 + 이미지)**
- 경쟁사 AI 도구는 주로 텍스트만 생성
- 우리는 인포그래픽까지 자동 생성
- 나노 바나나 수준의 전문가급 시각 자료

**5. 한국 시장 특화**
- 정부지원사업, IR 자료에 대한 깊은 이해
- 한국어 완벽 지원
- 한국 스타트업 생태계에 맞춘 기능

- 7개 노드: 문제 발굴, 문제 정의, 고객 개발, 시장 개발, 솔루션, 비즈니스 모델 캔버스, IR 자료
- 드래그앤드롭으로 노드 자유롭게 배치
- 완료 상태 시각화 (초록색: 완료, 노란색: 진행 중, 회색: 미시작)

**AI 대화 인터페이스**
- 각 노드 내에서 AI와 1:1 대화
- 채팅 UI로 질문/답변
- AI가 능동적으로 제안 (Proactive: "이 방향으로 가볼까요?")
- 문서 작성 도움 (가설, 인터뷰 질문지, 경쟁사 분석 등)

**프롬프트 템플릿 시스템**
- 자주 사용하는 프롬프트 저장
- 템플릿 카테고리 (문제 정의, 고객 개발, 경쟁사 분석 등)
- 사용자 정의 템플릿 생성
- 팀 템플릿 공유
- AI가 상황에 맞는 템플릿 추천

#### 3. 문서 작성 & 생성

**린스타트업 각 단계별 문서 템플릿**
- 문제 정의: 문제 기술서, 가설 정의서
- 고객 개발: 고객 페르소나, 인터뷰 질문지
- 시장 개발: 경쟁사 분석, 시장 규모 추정
- 솔루션: MVP 기능 명세서, 가치 제안서
- 비즈니스 모델: 9블록 캔버스
- IR 자료: 투자자 피칭 데크 (15페이지)

**AI 기반 문서 자동 생성**
- 사용자 기존 문서 임베딩하여 내용 반영
- RAG로 관련 정보 검색하여 문서에 통합
- Claude 4.5로 텍스트 생성
- GLM 4.7로 멀티모달 콘텐츠 생성 (차트, 그래프, 인포그래픽)

**문서 편집 & 내보내기**
- 간단한 Markdown 에디터 (Notion 스타일)
- 실시간 자동 저장
- PDF, DOCX로 내보내기

### MVP Success Criteria

#### 제품 성공 기준

**기술적 성공**
- 모든 핵심 + 추가 기능이 안정적으로 작동
- 버그 리포트 월 15건 미만
- 페이지 로드 시간 3초 미만
- AI 응답 시간 평균 10초 미만

**사용자 채택**
- 100명 활성 사용자 (Weekly Active Users)
- 주 3회 이상 로그인하는 사용자 60% 이상
- 노드 완료율 80% 이상
- 7일 리텐션 50% 이상
- 팀 기능 사용: 30% 이상의 사용자가 팀 기능 사용
- 대시보드 사용: 50% 이상의 사용자가 분석 대시보드 주 1회 이상 방문

**가치 창출**
- 10명 이상이 "bm-builder로 창업 시작했어"라고 피드백
- IR 자료 생성 시 사용자 만족도 (CSAT 4.0/5.0 이상)
- 정부지원사업 지원서 작성 시간 85% 이상 단축
- 팀 협업 효과: 팀 사용자의 만족도 4.5/5.0 이상

#### 학습 및 검증 (Learning & Validation)

**문제 검증**
- 사용자가 "AI 공동 창업자" 경험에 만족하는지
- 혼자 결정하는 고립감이 감소하는지
- (설문조사: "AI가 동료처럼 느껴지나요?" 4.0/5.0 이상)

**비즈니스 모델 검증**
- 프리티어에서 유료 티어 전환 의사 20명 이상
- 유료 요금제 지불 의사 금액 파악
- 액셀러레이터 제휴 관심 3개 이상

**기술적 타당성**
- RAG가 기존 문서를 제대로 임베딩하는지
- Node 기반 UI가 직관적인지
- AI가 의사결정에 도움이 되는지

#### Go/No-Go 의사결정 (Decision Point)

**3개월 후 MVP 성공 시:**
- 시리즈 A 투자 유치 준비
- 팀 확장 (개발자 1명, 디자이너 1명)
- 버전 2.0 개발 시작 (모바일 네이티브 앱, A/B 테스팅)

**3개월 후 MVP 실패 시:**
- 피벗 또는 종료
- (실패 정의: 활성 사용자 30명 미만, 리텐션 20% 미만)
